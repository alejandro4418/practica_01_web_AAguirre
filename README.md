## Descripción

Este proyecto consiste en el desarrollo de una página web que consume información de una API REST para obtener y mostrar los datos de un producto. El objetivo es practicar el consumo de servicios web y la manipulación de información mediante JavaScript.

## API utilizada

Se utiliza la API de Fake Store API para obtener los datos de un producto.

- **Servicio:** Fake Store API
- **Endpoint:** https://fakestoreapi.com/products/16
- **Método HTTP:** GET

La respuesta de la API contiene los siguientes datos del producto:

- **ID:** Identificador único del producto.
- **Title:** Nombre del producto.
- **Price:** Precio del producto.
- **Description:** Descripción detallada del producto.
- **Category:** Categoría a la que pertenece el producto.
- **Image:** URL de la imagen del producto.
- **Rating:** Objeto que incluye la calificación promedio (`rate`) y la cantidad de reseñas (`count`).
